# C++ Search

## Описание проекта

**C++ Search** — программа на C++, предназначенная для поиска заданного слова или подстроки в текстовых файлах и исходном коде.

Программа анализирует файл, находит строки, содержащие искомый текст, и выводит их номера и содержимое.

## Возможности

- Поиск заданного слова или подстроки в файле.
- Определение номеров строк, в которых найдены совпадения.
- Подсчёт количества найденных совпадений.
- Обработка ошибок при открытии файла.
- Проверка пустого поискового запроса.
- Хранение результатов поиска в векторе.

## Используемые библиотеки

- **`iostream`** — ввод и вывод данных.
- **`fstream`** — чтение файлов.
- **`string`** — работа со строками.
- **`vector`** — хранение результатов поиска.

## Компиляция и запуск

Для компиляции проекта используется CMake и установленный компилятор C++.

Сборка проекта из корневой папки репозитория:

```bash
cmake --build bin/build
```

Запуск программы из корневой папки репозитория:

```bash
./bin/build/main
```

Если сборка ещё не была настроена, сначала необходимо создать конфигурацию CMake. Для этого в папке, содержащей файл CMakeLists.txt, должен быть настроен проект.
    
## Инструкция по использованию

1. Запустить программу.
2. Ввести путь к файлу, в котором необходимо выполнить поиск.
3. Ввести слово или подстроку для поиска.

Если файл не удаётся открыть, программа выводит сообщение об ошибке и завершает работу.

Если совпадения отсутствуют, программа сообщает, что совпадений не найдено.

## Пример работы

```text
=== C++ Search ===
Введите имя файла: files/example.cpp
Введите слово для поиска: merge

Найдено совпадений: 2
Строка 4: int merge = 10;
Строка 7: cout << merge << endl;
```
