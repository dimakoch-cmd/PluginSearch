# PluginSearch

Плагин для VS Code, который ищет строки со словом в файле. Поиск выполняет консольная программа на C++, интерфейс расширения написан на TypeScript.

## Установка

1. Скачайте [plugin-search.vsix](dist/plugin-search.vsix) (откройте файл и нажмите «Download raw file»).
2. В VS Code: Ctrl+Shift+P → «Extensions: Install from VSIX...» → выберите скачанный файл.
3. Перезагрузите окно VS Code.
4. Ctrl+Shift+P → введите «Plugin Search» и выберите команду.

Требования: Linux (в том числе WSL Ubuntu). При работе через WSL выполните установку в окне VS Code, подключённом к WSL.

## Использование

Команды вызываются через Ctrl+Shift+P:

| Команда | Действие |
|---|---|
| Plugin Search: Поиск в выбранном файле | Вводите слово, выбираете файл в диалоге |
| Plugin Search: Поиск в активном файле | Поиск в файле, открытом в редакторе (как Ctrl+F). Если в редакторе выделено слово, оно подставляется в поле ввода |
| Plugin Search: Режимы поиска | Окно с галочками: учёт регистра, целое слово |

Результаты:

- Одно совпадение: курсор сразу переходит к строке, найденное слово выделяется.
- Несколько совпадений: список строк. При движении по списку редактор показывает строку, Enter фиксирует переход, Esc возвращает прежнее положение.

## Режимы поиска

- **Учитывать регистр** (по умолчанию включён). Без учёта регистра работают латиница и кириллица.
- **Целое слово** (по умолчанию выключен): `merge` не найдёт `mergeSort`.

Режимы выбираются командой «Режимы поиска» и сохраняются в настройках VS Code.

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| `pluginSearch.caseSensitive` | `true` | Учитывать регистр |
| `pluginSearch.wholeWord` | `false` | Искать только целые слова |
| `pluginSearch.binaryPath` | пусто | Путь к своему бинарнику `search`. Если пусто, используется встроенный |

## Ограничения

- Только Linux (проверено в WSL Ubuntu). Бинарник собран под версию системы, на которой выполнена сборка.
- Файлы должны быть в кодировке UTF-8. В других кодировках (например, cp1251) слова на кириллице не находятся, а текст строк отображается искажённо.
- Поиск идёт по файлу на диске. В режиме «в активном файле» несохранённые изменения сохраняются автоматически перед поиском.
- В каждой строке показывается первое совпадение.

## Структура проекта

| Папка | Содержимое |
|---|---|
| `bin/` | Исходный код консольной программы на C++ (`main.cpp`, `CMakeLists.txt`) |
| `extension/` | Расширение VS Code на TypeScript |
| `dist/` | Готовый файл `plugin-search.vsix` для установки |
| `files/` | Примеры файлов для проверки поиска |

## Сборка из исходников

Нужны `cmake`, `g++`, Node.js и npm.

```bash
cd extension
npm install
npm run package
```

Команда собирает C++ программу, копирует бинарник в `extension/bin/search`, компилирует TypeScript и создаёт `dist/plugin-search.vsix`. Установка собранного файла в WSL:

```bash
code --install-extension ../dist/plugin-search.vsix
```

## Разработка

Откройте корень проекта в VS Code и нажмите F5 (конфигурация «Run Extension»). В режиме разработки расширение берёт бинарник из `bin/build/search`, поэтому предварительно соберите C++ проект:

```bash
cd bin/build && cmake .. && make
```

## Формат вывода программы search

```
search [--ignore-case] [--whole-word] [--] <file> <query>
<номер строки> \t <колонка> \t <длина> \t <текст строки>
```

Колонка и длина заданы в байтах UTF-8, нумерация колонок с 0. Коды возврата: 0 успех, 1 неверные аргументы, 2 пустой запрос, 3 файл недоступен.
