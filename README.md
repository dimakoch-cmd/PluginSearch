# Плагин: Поиск в файле

Плагин для VS Code, который ищет строки со словом в файле. 

## Установка

1. Скачайте [plugin-search.vsix](dist/plugin-search.vsix) (откройте файл и нажмите «Download raw file»).
2. В VS Code: Ctrl+Shift+P → «Extensions: Install from VSIX...» → выберите скачанный файл.
3. Перезагрузите окно VS Code.
4. Ctrl+Shift+P → введите «Plugin Search» и выберите команду.

Требования: Linux (в том числе WSL Ubuntu). При работе через WSL выполните установку в окне VS Code, подключённом к WSL.

## Использование

Команды вызываются через Ctrl+Shift+P:

| Команда | Действие |
|---|---|
| Plugin Search: Поиск в выбранном файле | Вводите слово, выбираете файл в диалоге |
| Plugin Search: Поиск в активном файле | Поиск в файле, открытом в редакторе (как Ctrl+F). Если в редакторе выделено слово, оно подставляется в поле ввода |
| Plugin Search: Режимы поиска | Окно с галочками: учёт регистра, целое слово |

Результаты:

- Одно совпадение: курсор сразу переходит к строке, найденное слово выделяется.
- Несколько совпадений: список строк. При движении по списку редактор показывает строку, Enter фиксирует переход, Esc возвращает прежнее положение.

## Режимы поиска

- **Учитывать регистр** (по умолчанию включён)
- **Целое слово** (по умолчанию выключен)

Режимы выбираются командой «Режимы поиска» и сохраняются в настройках VS Code.
